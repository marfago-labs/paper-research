# User facts

A running log of facts about the user, added to in every interaction. Facts from papers go in `pins.md`.

Format: `YYYY-MM-DD | type | basis | fact`

- **Type:** `question`, `interest`, `preference`, or `way-of-working`.
- **Basis:** `stated` (the user said it), `observed` (the user did it), or `inferred` (a guess, saved only if the user agrees).
- **Question scope:** log questions about papers and ideas, not workspace setup.
