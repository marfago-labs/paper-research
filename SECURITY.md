# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue, so they can be fixed before they are known.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**, or go
straight to [the report form](https://github.com/marfago-labs/paper-research/security/advisories/new).

Include:

- what you found, and what it lets an attacker do, such as getting data out of a workspace or changing a file without
  approval
- the steps to reproduce it, such as a paper, page, or prompt that triggers it
- the plugin version, your operating system, and your Claude Code version

Leave out your own notes and any private data.

## Supported versions

Fixes go into the latest release only. Update the plugin to get them.

## Scope

What the plugin protects against, and what it doesn't, is described in [Security](docs/security.md). A problem in
Claude Code itself, outside this plugin, belongs to Anthropic: see its
[security policy](https://www.anthropic.com/responsible-disclosure-policy).
